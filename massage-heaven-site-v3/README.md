# Massage Heaven — wersja 3

## Uruchomienie
Otwórz `index.html` w przeglądarce albo opublikuj cały folder na statycznym hostingu (np. GitHub Pages / Cloudflare Pages). Nie przenoś sam plik `index.html` bez folderu `assets`.

## Zawartość
- `index.html` — strona główna, portfolio, profile zespołu, katalog usług i formularz zapytania o termin.
- `assets/` — zdjęcia WebP, w tym nowe zdjęcie masażu twarzy przekazane przez właściciela.
- `privacy.html`, `rodo.html` — widoczne strony-zagłuszki do uzupełnienia przed publikacją.

## Formularz zapytania
Formularz nie potwierdza dostępności terminu automatycznie. Po wypełnieniu otwiera WhatsApp z przygotowaną wiadomością na numer +48 731 711 509. Wizyta zostaje umówiona dopiero po odpowiedzi gabinetu. To frontendowy etap; do prawdziwej rezerwacji z kalendarzem i aktualnymi slotami potrzebny backend oraz synchronizacja kalendarzy obu masażystek.

## Prимечания перед публикацией
- Potwierdzić numer WhatsApp.
- Zastąpić tymczasowy link Google Maps bezpośrednim linkiem do profilu Google Business / opinii.
- Uzupełnić portrety i opisy Angeliki oraz Anastazji (nie dodano niepotwierdzonych specjalizacji ani certyfikatów).
- Uzupełnić dokumenty `privacy.html` i `rodo.html` po konsultacji prawnej.
- Potwierdzić ceny, czasy i opisy zabiegów.
- Wideo można osadzić z Vimeo, gdy będzie gotowy publiczny link do filmu.
